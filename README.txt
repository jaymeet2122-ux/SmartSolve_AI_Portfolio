SMARTSOLVE AI — LIGHT GLASS PORTFOLIO

Files:
- index.html: website content and structure
- style.css: light glassmorphism styling and responsive layout
- script.js: mobile navigation and scroll reveal effects
- assets/: project screenshots
- SmartSolve_AI_Project_Portfolio_Jaymeet_Patel.pdf: downloadable project report

PREVIEW LOCALLY
1. Open this folder in Visual Studio Code.
2. Open index.html.
3. Right-click and choose Open with Live Server (if installed).

PUBLISH TO YOUR EXISTING GITHUB PAGES SITE
1. Keep a backup of your current published repository files.
2. Upload the contents of this folder to the SAME repository and publishing branch.
3. Replace the old index.html, style.css, and script.js.
4. Upload/merge the assets folder and PDF, preserving their names and paths.
5. Commit the changes. GitHub Pages will redeploy the site at the same URL.

This is a static portfolio website. It does not run the SmartSolve AI Flask application.
